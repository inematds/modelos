# Tarefa braçal com Luna

Só para tarefa **sem ambiguidade**. Se você precisa explicar "o que eu quis dizer", não é Luna.

- Simples/rápida (renomear, extrair, formatar) → **Luna Low**
- Pesada/operacional (muitos arquivos, lote grande) → **Luna High / X-High**

```
Tarefa: <verbo + objeto exato>
Entrada: <onde está>
Saída: <formato exato, com 1 exemplo>
Regras:
- Não altere nada além do pedido.
- Se um item não se encaixar na regra, pule e liste no final.
Ao terminar: quantos itens processados, quantos pulados (e quais).
```

**Lote:** teste 1 item primeiro. Passou → manda o lote inteiro.
