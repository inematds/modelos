# Planejar com Astra → executar com Sol

Modelo forte decide **o quê**; modelo barato faz **o como**. O plano é o contrato entre os dois.

## Passo 1 — Astra (médio–alto)

```
Objetivo: <o que quero no fim>
Contexto: <projeto, restrições, o que já existe>

Faça um plano de execução para outro modelo (mais simples) seguir sem precisar decidir nada:
1. Passos numerados, cada um verificável ("pronto quando...").
2. Arquivos/comandos exatos em cada passo.
3. Riscos e o que fazer se cada um acontecer.
4. O que NÃO fazer.
Se algo estiver ambíguo, liste as perguntas antes do plano.
```

## Passo 2 — Sol (médio–alto)

```
Execute o plano abaixo passo a passo. Não mude o plano.
Após cada passo, rode a verificação indicada e diga o resultado real.
Se um passo falhar ou algo não estiver no plano, PARE e descreva — não improvise.

<cole o plano>
```

**Por que funciona:** a parte cara (julgamento) acontece uma vez; a parte longa (execução) sai barata.
