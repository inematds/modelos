# Segunda opinião (caso ambíguo): Astra + Opus 5.5

Use quando há vários caminhos plausíveis e errar é caro. Substitui gastar com Fable.

## Passo 1 — Astra propõe
Peça o plano/decisão normalmente (ver `planejar-executar.md`, passo 1).

## Passo 2 — Opus 5.5 (baixo) revisa

```
Outro modelo propôs a decisão abaixo para este problema.

Problema: <descrição>
Proposta: <cole>

Revise como um revisor cético:
1. A proposta resolve o problema real? O que ela assume sem provar?
2. Os 2 maiores riscos, e como cada um apareceria na prática.
3. Uma alternativa mais simples, se existir.
4. Veredito: seguir / seguir com ajustes (quais) / refazer.
Seja curto e direto.
```

**Decisão:** se os dois concordam → siga. Se discordam → a divergência é o ponto a resolver (por você).
